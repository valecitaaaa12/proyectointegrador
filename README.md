# AVIOR Corporation SRL — Proyecto Integrador

## 📌 Descripción
Sistema web institucional para **AVIOR Corporation S.R.L.**, Centro de Instrucción de Aeronáutica Civil certificado por la DGAC Bolivia bajo RAB 141 y 142.

El sitio incluye:
- **Página institucional** (index.html) — Carreras, sedes, contacto
- **Sistema de autenticación** (login.html) — Roles: Admin, Instructor, Estudiante
- **Dashboard académico** (dashboard.html) — Gestión de estudiantes, cursos, calificaciones

## 🚀 Tecnologías
- HTML5, CSS3, JavaScript (Vanilla)
- LocalStorage para persistencia de datos
- Diseño responsive

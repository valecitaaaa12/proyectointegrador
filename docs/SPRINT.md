# 🏃 Sprint 1 — AVIOR Corporation

## 📅 Duración
**Fecha inicio:** 27 de septiembre de 2026  
**Fecha fin:** 4 de octubre de 2026  
**Duración:** 1 semana

---

## 🎯 Objetivo del Sprint
Desarrollar el sitio web institucional y sistema académico básico para AVIOR Corporation SRL, incluyendo página principal, autenticación y dashboard funcional.

---

## 📋 Historias de Usuario

### AVIOR-001: Sitio Institucional
**Como** visitante del sitio web  
**Quiero** ver información sobre la escuela, carreras y sedes  
**Para** decidir si quiero estudiar allí

**Criterios de aceptación:**
- [x] Página principal con hero atractivo
- [x] Sección de carreras (Piloto Civil, TCP, EOV)
- [x] Sección de sedes (La Paz, Cochabamba, Tarija, Sucre)
- [x] Formulario de contacto
- [x] Diseño responsive

**Estado:** ✅ Completado  
**Rama:** `feature/AVIOR-001-sitio-institucional`

---

### AVIOR-002: Sistema de Autenticación
**Como** usuario del sistema  
**Quiero** iniciar sesión con diferentes roles  
**Para** acceder a funcionalidades según mi rol

**Criterios de aceptación:**
- [x] Formulario de login con email y contraseña
- [x] Roles: Admin, Instructor, Estudiante
- [x] Validación de credenciales
- [x] Mensajes de error apropiados
- [x] Persistencia de sesión

**Estado:** ✅ Completado  
**Rama:** `feature/AVIOR-002-sistema-autenticacion`

---

### AVIOR-003: Dashboard Académico
**Como** usuario autenticado  
**Quiero** ver un panel de control según mi rol  
**Para** gestionar estudiantes, cursos y calificaciones

**Criterios de aceptación:**
- [x] Dashboard con sidebar de navegación
- [x] Módulos según rol (Admin, Instructor, Estudiante)
- [x] Tablas de estudiantes y cursos
- [x] Estadísticas básicas
- [x] Cierre de sesión

**Estado:** ✅ Completado  
**Rama:** `feature/AVIOR-003-dashboard-academico`

---

### AVIOR-004: Páginas Secundarias
**Como** visitante  
**Quiero** navegar a páginas detalladas de cada sección  
**Para** obtener información completa

**Criterios de aceptación:**
- [x] Página de carreras detallada

### AVIOR-005: Mejoras UX/UI
